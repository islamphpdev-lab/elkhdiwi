# الكلمات البحثية لموقع بن الخديوي

- `keywords.csv`: 70 كلمة بحثية مع الصفحة المستهدفة والأولوية ونية البحث والمنافسة المتوقعة.
- `page-plan.csv`: العنوان (Title) والوصف (Meta Description) وعنوان H1 المقترح لكل صفحة.

الملفان يفتحان في Excel و Google Sheets. عمود «حجم البحث الشهري» فارغ عمداً: املأه من Google Keyword Planner.
